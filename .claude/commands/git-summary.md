# Git 改动摘要

请执行以下步骤，生成本次改动的中文摘要：

## 步骤

1. 运行 `git status` 查看工作区状态
2. 运行 `git diff HEAD` 查看所有改动（已暂存 + 未暂存）
3. 运行 `git log --oneline -5` 查看最近5条提交

## 输出格式

按以下结构输出中文摘要：

```
## 改动摘要

**改动类型**: [新功能 / Bug修复 / 重构 / 文档 / 样式]

**影响范围**:
- 涉及文件数：N 个
- 主要模块：...

**改动内容**:
1. ...
2. ...

**建议 commit message**:
feat/fix/refactor: ...
```

如果工作区是干净的（无改动），请提示用户当前没有未提交的改动。
