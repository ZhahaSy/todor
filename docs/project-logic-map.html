4. 核心：AiService.process 决策流

forceIntent 来自请求体 mode（可选 chat | todo | deepdive），有值时跳过 LLM 意图识别。意图识别模型输出的类型见代码中的 schema（含 todo/chat/reminder/query/email/agent；deepdive 通常由前端 mode 强制指定）。
